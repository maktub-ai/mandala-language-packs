# Language contributions have moved

Please submit language packages and translation improvements to [mandala-plugins](https://github.com/maktub-ai/mandala-plugins), following the [language contribution guide](https://github.com/maktub-ai/mandala-plugins/blob/main/docs/languages.md).

This repository accepts compatibility maintenance only. Keep `catalog.json` in the `mandala-catalog` v1 language format, preserve existing IDs and minimum legacy App versions, and point packages at real commits and exact checksums in `mandala-plugins`. Synchronize entries with its `catalogs/languages.json` after validating the new payload. Never delete or rewrite historical package commits as part of this migration.

Retain the repository for older Apps and fixed commit references. Keep it private until separate owner approval. Do not add cloud workflows, credentials, personal data, or real-user screenshots.
